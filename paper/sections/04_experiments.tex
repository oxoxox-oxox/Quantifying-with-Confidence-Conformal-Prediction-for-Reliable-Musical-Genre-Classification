\section{Experiments}
\label{sec:experiments}

\subsection{Setup}

\textbf{GTZAN}~\cite{tzanetakis2002gtzan} (999 tracks, 10 genres) and
\textbf{FMA Small}~\cite{defferrard2017fma} (7,994 tracks, 8 genres). Embeddings
are $\ell_2$-normalized 1024-dim vectors from MERT-v1-330M. We use stratified
5-fold 60/20/20 splits; the Linear Probe is trained for 100 epochs (Adam,
$\text{lr}=10^{-3}$, $\text{weight\_decay}=10^{-2}$). We evaluate at $\alpha
\in \{0.05, 0.10\}$.

\subsection{Embedding Quality}

On GTZAN, MERT embeddings achieve intra-class cosine similarity $0.917$ vs.\
inter-class $0.873$ ($\Delta = 0.044$). Classical and metal are well-separated;
rock and country overlap, consistent with perceptual ambiguity. On FMA,
separation is substantially weaker ($\Delta = 0.026$), reflecting more entangled
genre categories.

\subsection{Coverage and Set Size}

To establish a performance baseline, we first evaluate the underlying Linear Probe's Top-1 classification accuracy.
The base model achieves a Top-1 accuracy of $76.5 \pm 2.5\%$ on GTZAN and $53.5 \pm 1.1\%$ on FMA Small.
This performance gap sets the stage for demonstrating Conformal Prediction's adaptability: a traditional classifier would silently output an incorrect single label for nearly half of the FMA tracks.

\textbf{LP-Cos-CP} achieves strict class-conditional coverage matching nominal targets on both
datasets via Mondrian Conformal Prediction. At the default $\alpha = 0.05$ setting (95\% confidence), the system
returns 4.0 genres on GTZAN and 5.2 on FMA; at $\alpha = 0.10$, sets shrink to
2.7 genres on GTZAN (4.0 on FMA), meaning a user typically inspects only a few
candidates rather than the full label space. Set size distributions (Figure~\ref{fig:set_size_boxplot}) confirm
compact sets predominate.

\textbf{Bootstrap} produces seemingly tight sets but catastrophically fails under class-conditional constraints (dropping to $0.862$ vs.\ nominal $0.90$ at $\alpha=0.10$ on GTZAN). It breaks the system's confidence promise for individual classes, proving unreliable under strict evaluation.

\textbf{Gaussian} relies on parametric normality assumptions that interact unpredictably with score distribution shape. While it sometimes achieves target coverage, it lacks the rigorous distribution-free guarantees of LP-Cos-CP, making its interface behavior fail in ways users cannot anticipate.

\subsection{Cross-Dataset Robustness}

Despite FMA's weaker embedding separability ($\Delta = 0.026$) and significantly lower base Top-1 accuracy ($53.5\%$), LP-Cos-CP's
distribution-free guarantee ensures valid class-conditional coverage. The model's inherent uncertainty is directly reflected in the
proportionally larger set sizes on FMA ($4.02$ at $\alpha=0.10$).
Rather than being a limitation, this expansion is precisely the desired behavior: CP adaptively broadens the prediction set to maintain the coverage guarantee, providing honest feedback that informs users when the model lacks the confidence to make a narrow prediction.

In summary, learned prototypes substantially improve the user experience by
shrinking prediction sets, the $\alpha$ parameter functions as an effective
trust slider, and distribution-free calibration is a practical necessity for
predictable interface behavior.
