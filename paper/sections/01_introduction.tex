\section{Introduction}

Music genre classification underpins countless user-facing AI tools: streaming
platforms curate playlists by genre, producers filter AI-generated tracks by
style, and recommendation systems surface musically similar content. Yet these
tools share a critical limitation: they produce a single label with no
indication of confidence. A DJ receiving ``rock'' as a classification cannot
distinguish a high-confidence judgment from a guess near a genre boundary. This
\emph{trust gap}---the inability to calibrate trust in AI outputs without
confidence signals---is a well-documented problem in human-AI
interaction~\cite{amershi2019guidelines,miller2019explanation}. Over-trust leads
to uncritical error acceptance; under-trust triggers unnecessary manual
verification, undermining the efficiency AI tools promise.

Existing approaches for communicating model uncertainty fall short for
non-expert users. Post-hoc explanation methods such as
LIME~\cite{ribeiro2016lime} highlight influential input features but provide no
statistical coverage guarantee. Bayesian techniques produce variance estimates
that are opaque to users without probability training. What users need is a
confidence signal interpretable at a glance and backed by a formal guarantee
that the correct answer is included.

Conformal prediction (CP)~\cite{vovk2005algorithmic,angelopoulos2023gentle}
offers a promising foundation: a distribution-free framework that constructs
\emph{prediction sets} $\Gamma_\alpha(x)$---subsets of candidate labels
guaranteed to contain the true label with probability $\geq 1-\alpha$---under
only the assumption of exchangeable calibration and test data. While CP has been
applied to regression and image classification~\cite{romano2019conformalized,angelopoulos2021uncertainty},
its potential as a \emph{user interface primitive} remains unexplored. Set
cardinality is intuitively interpretable (smaller = more confident), and the
significance level $\alpha$ functions as an explicit trust slider that users can
adjust without statistical expertise.

We propose LP-Cos-CP, a framework that transforms music genre classification
from an opaque single-label prediction into an interpretable prediction set
interface. Our pipeline consists of three stages: (1)~extracting 1024-dim
embeddings from the last hidden layer of MERT-v1-330M~\cite{li2023mert}, a
self-supervised music model, via mean-pooling over time; (2)~training a Linear
Probe with cross-entropy to learn discriminative genre prototypes $\mathbf{W}_k$
on a reference set; and (3)~calibrating cosine-distance nonconformity scores via
empirical $p$-values to produce prediction sets with formal coverage
guarantees. The set size serves as an immediately interpretable confidence
signal, and $\alpha$ serves as a user-adjustable trust slider.

We evaluate LP-Cos-CP on GTZAN ($N=999$, $K=10$ genres) and FMA Small
($N=7{,}994$, $K=8$ genres). At $\alpha = 0.10$, the average prediction set
on GTZAN contains 2--3 genres (vs.\ 5--6 for centroid-based prototypes), narrowing the
user's attention to a focused candidate list.
Crucially, on FMA Small, where the base classifier's Top-1 accuracy drops to 53.5\%,
the prediction set adapts by expanding to an average size of 4.1. This ensures that the
system maintains empirical coverage at or above nominal targets even when model uncertainty is high, effectively replacing silent misclassifications with honest abstentions. A controlled
comparison of Bootstrap and Gaussian calibration reveals that only
distribution-free CP calibration produces predictable, usable interface
behavior. Our contributions are:

\begin{enumerate}[leftmargin=*,itemsep=0pt]
    \item A user-facing framework for music genre classification where
    prediction set size communicates confidence without statistical expertise,
    and $\alpha$ provides an explicit trust slider (Section~\ref{sec:methodology}).
    \item Empirical evidence that learned prototypes reduce set sizes by up to
    55\% compared to centroid baselines while maintaining valid coverage
    (Section~\ref{sec:experiments}).
    \item Design implications for integrating prediction sets as an interface
    layer in music AI tools, including confidence-guided filtering and
    human-in-the-loop workflows (Section~\ref{sec:discussion}).
\end{enumerate}
